# CoreKV 范围扫描计划

**目标：** 提供按键升序的有界范围扫描，正确处理 MemTable、多个 SST 的覆盖和删除标记。

**接口：** `DB::Scan(begin, end, limit)` 返回键值对。范围为 `[begin, end)`；空 `end` 表示无上界，`limit` 限制可见结果数量，0 返回空。键排序与现有 `std::map<std::string,...>` 一致。

**实现：** 从 MemTable 和每个 SST 的索引定位第一个不小于 `begin` 的键。每轮取所有来源的最小键，选择最新来源的值，并跳过删除标记。只读取要返回的 SST 记录；不将所有 SST 的值一次装入内存。复用 DB 的互斥锁与 SST 校验路径。

**验证：**

1. 先写覆盖、删除、边界、数量限制与重启/压实后结果的测试，确认因接口缺失而失败。
2. 增加 SST 索引游标能力，再实现 `DB::Scan`，确认新测试通过。
