# CoreKV 批量写入计划

**目标：** 提供一次 WAL 同步确认的有序 Put/Delete 批量写入；重放时只应用完整且校验正确的整批记录。

**接口：** `DB::WriteBatch(const std::vector<Mutation>&)`，`Mutation{key, optional<value>}`，空值表示删除。空批次是无操作；同键重复时最后一项生效。键/值仍遵守原有大小限制，最多 1024 项，整批记录体最多 4 MiB。

**格式：** 保留现有 8 字节长度与 CRC32 记录头和单项 `0x01/0x02` WAL 记录。新增 `0x03 | u32 count | count × (op | u32 key_len | u32 value_len | key | value)` 作为单条 WAL 记录。SST 仍只接受单项记录。完整记录校验失败时报损坏；尾部不完整记录按原有规则截断。

**顺序：** 先验证全批，编码成单条 WAL 记录并同步，然后在 DB 互斥锁内按顺序更新 MemTable。恢复时先完整解码一条记录，再把全部变更应用到 MemTable。超过阈值时整批应用后才刷盘。

**验证：**

1. 测试混合 Put/Delete、同键覆盖、重启恢复、空批次与无效批次拒绝，确认接口缺失时失败。
2. 实现格式编解码与 WAL 追加/重放，确认成功批次通过测试。
3. 测试被截断的批量 WAL 记录不应用任何一项，已确认批次在进程直接退出后可恢复。
4. 基准程序支持指定批量大小，记录批量大小与写吞吐；运行全量回归和严格编译，审查后提交本地 Git。
